# NIST SP 811 in Out of Spec

All player-facing text (UI strings in `scripts/` and `*.tscn`, and the text in `data/*.json`) follows NIST SP 811 (2008 ed.), the same rules as Ryan's training material in the AI Router (`review-training/SP811-RULES.md`). Ryan's call, 2026-11-21.

Check before every push:

```
python tools/check_sp811.py
```

It exits non-zero and lists `file:line` for each violation. Format numbers in GDScript with `SP811` (`scripts/ui/sp811.gd`), never with a bare `%+.2f`, so signs and grouping come out right.

| Rule | Right | Wrong |
|---|---|---|
| Space between number and unit symbol (§7.2) | 50 ms, 24 °C, 80 % | 50ms, 24°C, 80% |
| Plane-angle degree: no space | 4.00° | 4.00 ° |
| No qualifiers or information on unit symbols (§7.4, §7.5) | relative humidity 73.6 % | 73.6 %RH |
| Minus sign U+2212 in computed values | −0.48° | -0.48° |
| Digit grouping over four digits, narrow no-break space U+202F, never commas (§10.5.3) | 12 000 | 12,000 |
| Four digits or fewer: no grouping | 1500 | 1 500 |
| Multiplication sign | 1.230 × MPE | 1.230 x MPE |
| Standard abbreviations only (§6.1.8) | s, h, min, d | sec, hr, mins |
| Value with uncertainty or a range: parentheses, unit once (§7.7) | (1.20 ± 0.10) kg | 1.20 ± 0.10 kg |
| A percentage is not added to an absolute value (§7.10.2) | 500 × (1 ± 10 %) kPa | 500 kPa ± 10 % |

Game-only conventions: credits are "CR" (not an SI unit, so free-form); clock times are 24 h "06:00"; "d" is the day symbol in intervals.
