# Tarantula Shop reference

This folder is reference only. It is a snapshot of useful material from the retired game The Tarantula Shop (v0.1.14, final commit `eda0dccbc6bc52945efe5488cf31e3a94fc39207`). It is not game data and must not be loaded by the simulation.

`data/tarantula_species.json` is the canonical species table for Out of Spec. Do not overwrite it from these files without a Facts pass and Ryan's OK.

Humidity values already disagree. The shop catalog tags Curly Hair (*Tliltocatl albopilosus*) as `humidity: "dry"`; Out of Spec uses an ideal relative humidity of 68 %. Only Curlyhair and Mexican Redknee overlap. Brazilian Black (*Grammostola pulchra*) is in Out of Spec and is not in the shop catalog.

Checklist paths still point at the old shop repo. For playtesting this game, use `docs/playtest.md`.
